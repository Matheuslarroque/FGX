# FGX — Site One-page + Loja
Next.js + Tailwind.

## Rodar localmente
1) Instale as dependências:
   npm install

2) Dev:
   npm run dev

3) Build e start:
   npm run build
   npm start

## Deploy (Vercel)
- Crie um projeto na https://vercel.com e importe esta pasta.
- A Vercel detecta Next.js automaticamente.
